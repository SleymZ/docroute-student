# Chat video (en, ru, hi) — a different style

Light theme (cream #f3efe8, coral #d4502f), a generic messenger (not a copy
of any real app), no voice: a friend writes "I GOT IN", panics about visa,
residence permit and apostille, is asked about the passport, gets the answer
for it (entry visa + residence permit for study) and DocRoute; "free to
start, link's in their profile". Typing dots, pop/swoosh sounds, a light
synthesized lo-fi beat; "Story dramatized" in the corner.
Reading time per message: typing 0.45–1.1 s, then 0.55 s + 0.045 s per character.

```bash
node marketing/chat/render.mjs en ru hi   # → out/DocRoute-chat-<lang>.mp4 and -sounds-only-
```
